## TEXT-1 — 0.1.20

Очистка текста анкеты и ответов снимала невидимые знаки по перечню кодов; знак вне перечня (метка языка,
монгольский разделитель, арабские форматирующие знаки, связки вне эмодзи) оставался в тексте на экране и в файле
ответов. `clean` берёт из общего `secret-view.ts` правило невидимости: невидим любой управляющий или
форматирующий знак; акцент при букве и связка эмодзи остаются. Секреты в тексте анкеты не ищутся: ответ владельца,
похожий на ключ или пароль, доходит до агента таким, каким введён (`TEXT-3`). Вариант исполнителя с заменой по
шаблонам отклонён при сверке. Набор: 129 тестов, 0 отказов; 16 новых падали до правки.

## FIELD-1, FIELD-2 — 0.1.21

Работа исполнителя (Codex), сверена и доработана. Поле ответа: набранный текст родное поле хранит у движка, пока мод рисует прежнее значение; мод возвращал набор в значение поля, и отрисовка, опоздавшая к следующим нажатиям, стирала набранные за это время знаки (тот же дефект, что в поиске задач Cockpit 0.16.82; прочитан в коде движка Claude Code 2.1.293); здесь между нажатием и отрисовкой стоит
запись файла ответов на каждый знак. Теперь значение поля при наборе не меняется; программная установка и очистка рисуют значение, отличное от нарисованного в последний раз, — для пустого это пустая строка вместо отсутствия значения и обратно; ответ по-прежнему сохраняется в файл на каждый знак.
При сверке найдено и исправлено: движок хранит набранное по ключу поля — номеру вопроса, общему для всех анкет,
— а пустое значение выбиралось одним переключателем на все поля. После работы с полем другого вопроса текст,
стёртый выбором готового варианта, либо текст того же по счёту вопроса другой анкеты оставался в поле.
Пустое значение выбирается от последнего нарисованного для этого же вопроса; тест `FIELD-2` падает на варианте
исполнителя. Не исправлено: в низкой панели на поверхности vscode номер поля в кольце фокуса меняется при
наборе. Набор: 139 тестов, 0 отказов.

вопросов на указатель не реагируют (жалоба владельца: фиолетовым красилась каждая строка описания). Анкета,

Сообщение о заполнении по замыслу дописывается в строку ввода, путь к ответам агент получает скрытым блоком.
Работа исполнителя (Codex), сверена. Набор: 146 тестов, 0 отказов. Живой терминал не проверялся.
