# Survey 0.1.24

Анкета в панели Claude Code для выбора архитектуры и ответов на несколько вопросов. Визуальная основа — FileTree: дерево рядов, значки, наведение, шапка и подвал. Цвета берутся из темы хоста, включая светлую. `glyphs` по умолчанию `nerd`; `plain` даёт обычные Unicode-значки, `auto` использует их вне терминала.

Агент через встроенный скилл `survey-authoring` пишет `.cockpit/surveys/<id>.json`; после Write/Edit панель открывается автоматически. Если терминал не разместил панель, появится кнопка `/survey` над строкой ввода. На старте сессии восстанавливается последняя незавершённая анкета. Если события старта или записи пропущены и активной анкеты нет, следующий запрос владельца проверяет каталог и восстанавливает незавершённую анкету.

Штатный вопрос `AskUserQuestion` отклоняется с указанием составить анкету: у него предел в четыре вопроса по четыре варианта, у анкеты — 40 вопросов по 12 вариантов с пояснениями и свободным текстом. Секция системной подсказки сообщает об этом агенту заранее; в режимах `print` и `bare` она не добавляется.

- `/survey [id]` — открыть последнюю или указанную анкету.
- `/survey list` — показать список id через toast.
- `/survey answer <questionId> <текст>` — свой ответ в текущей анкете, в том числе на mobile без Input.
- `/survey open <id>` — открыть id, совпавший с командой, например `list`.
- `j/k`, стрелки — перемещение; Enter/Space — выбор; ←→ — раскрытие; Tab/n — следующий неотвеченный вопрос. Мышь выбирает ряд; наведение показывает детали варианта.

Наведение подсвечивает только нажимаемую метку варианта или поля ответа; фрагменты метки разделяют один `hover.scope`. Строки описания, вступление и текст вопроса самостоятельно не подсвечиваются. Подписи действий появляются только при наведении на значок, а не при фокусе клавиатуры.

Ответы сохраняются после каждого выбора/изменения текста в `<id>.answers.json`. Для single свой текст заменяет выбор; для multi дополняет его. Сброс очищает ответы и ожидающую передачу. Отправка отмечает `complete`, закрывает панель и добавляет в черновик строку `Анкета «<id>» заполнена.`, сохраняя существующий текст. Путь к ответам передаётся агенту отдельным скрытым блоком контекста, когда человек отправляет сообщение с этой строкой. При отказе submit или удалённой строке передача остаётся ожидающей; повторное «Отправить» заменяет её. Название с управляющими символами заменяется идентификатором анкеты. Неполная анкета сначала предупреждает и переходит к первому пропуску; второе нажатие отправляет её как есть. Мод сам сообщение не отправляет и модель не вызывает.

Формат, пример и пределы — [skills/survey-authoring/SKILL.md](skills/survey-authoring/SKILL.md). Управляющие и bidi-символы удаляются, текст ограничивается по длине. Ошибки показывают короткую причину без содержимого. Симлинки в каталоге и файлах отклоняются, включая оборванные ссылки. Запись атомарная: собственный временный файл, `fsync`, `os.replace`.

Файловые операции требуют хоста Claude Code CLI на Linux/macOS с `python3` и `O_NOFOLLOW`/`dir_fd`. API 2.1.289 предоставляет `fs.write`, но не rename; поэтому фиксированный помощник [hooks/files.py](hooks/files.py) вызывается через `process.run` без shell, данные передаются через stdin. На хосте без этих средств мод выдаёт короткую ошибку и не заменяет запись неатомарным способом. Поверхности terminal, desktop, mobile и vscode проверяются тестами с хостом CLI; нативные удалённые хосты без process API не поддерживают сохранение.

Проверка из корня репозитория:

```sh
mkdir -p .tmp
TMPDIR="$PWD/.tmp" claude plugin test agents/claude/plugins/survey
TMPDIR="$PWD/.tmp" claude plugin validate agents/claude/plugins/survey
TMPDIR="$PWD/.tmp" PYTHONDONTWRITEBYTECODE=1 python3 agents/claude/plugins/survey/tests/files.test.py
```
